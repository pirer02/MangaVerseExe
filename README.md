# 📖 MangaVerse

![Firebase](https://img.shields.io/badge/Firebase-FFCA28?style=for-the-badge&logo=firebase&logoColor=white)

MangaVerse es un ecosistema de lectura y gestión de manga diseñado para ofrecer una experiencia unificada a través de múltiples dispositivos (Android, iOS y Escritorio).

## ✨ Características Principales
* **Experiencia Multiplataforma:** Código base compartido para despliegue en móvil y escritorio.
* **Sincronización en la nube:** Gestión de usuarios y base de datos en tiempo real mediante Firebase.
* **Interfaz Moderna:** UI construida íntegramente de forma declarativa.

## 🛠️ Arquitectura y Tecnologías
* **Lenguaje:** Java
* **Backend as a Service (BaaS):** Firebase (Autenticación, Firestore, Storage)
